# osint-skills

Passive, publicly-available-information OSINT skill for AI coding agents.

## osint-ultimate

Covers domain/infrastructure recon (WHOIS, DNS, certificate transparency, ASN/IP ownership, Shodan/Censys), bug-bounty scoping and passive recon methodology, search-engine dorking and document-metadata forensics, social media verification and cross-platform username checks, image/video geolocation verification, corporate research, breach self-audit, email-security posture audit, and reporting templates.

Scoped to passive research only. Does not include exploit tooling, credential validators, or techniques for locating/tracking private individuals. See `skills/osint-ultimate/SKILL.md` for the full boundary statement.
