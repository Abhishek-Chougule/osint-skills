# osint-skills

Passive, publicly-available-information OSINT skill for AI coding agents.

## osint-ultimate

Covers domain/infrastructure recon, bug-bounty scoping and passive recon methodology, social media verification, image/geolocation verification, corporate research, breach self-audit, email-security posture audit, and reporting templates.

Scoped to passive research only. Does not include exploit tooling, credential validators, or techniques for locating/tracking private individuals. See `skills/osint-ultimate/SKILL.md` for the full boundary statement.

## Install

```
npx skills add <your-github-username>/osint-skills
```
